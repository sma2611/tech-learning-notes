# 3.2 Структура JDK

## Что входит в JDK
- **JDK** (Java Development Kit) = JRE + инструменты разработчика
- **JRE** (Java Runtime Environment) = JVM + стандартные библиотеки
- **JVM** (Java Virtual Machine) — исполняет байт-код

## Ключевые утилиты
| Команда | Назначение |
|---------|-----------|
| `javac` | Компилятор: `.java` → `.class` (байт-код) |
| `java`  | Запуск байт-кода на JVM |
| `javadoc` | Генерация документации из комментариев |
| `jar` | Упаковка классов в архив |
| `jdb` | Отладчик |

## Цепочка выполнения
Main.java → javac → Main.class → JVM → машинный код
