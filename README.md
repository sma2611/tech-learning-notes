## ⚠️ Note About File Names

This is an educational repository, so you may notice:

- Duplicate file names: Multiple `Main.java` files in different folders (e.g., `01-hello-world/Main.java`, `02-variables/Main.java`). This is intentional — each file demonstrates a specific concept independently.

- Multiple classes in one file: Some Java files may contain several classes for demonstration purposes. In production code, each public class would be in its own file, but for learning, keeping related examples together is more convenient.

These practices are **not recommended for production projects**, but they work well for educational purposes and quick experimentation.
